## 주요 발견 및 개선 포인트

### 1. 검색 품질 (가장 큰 문제)
- ground truth 출처가 특정 보험사의 특정 조문인데, 질문에 보험사명이 없어서 검색이 안 됨
- Silver 생성 시 질문에 보험사/상품명을 포함시키거나, ground truth 출처를 더 넓게 잡아야 함

### 2. 거절 능력 (0%)
- 거절해야 할 질문(수수료, 추천 등)에 AI가 답변을 생성함
- 거절 판별 로직(키워드 매칭)이 너무 단순 → LLM 기반 거절 판별로 개선 필요

### 3. 규칙 기반 vs LLM 평가 비교
- 규칙 기반 must_include 23% vs LLM 키워드 정확도 72% → LLM이 의미적 매칭으로 더 정확
- 규칙 기반은 "동일사고당 1회 지급" ≠ "동일사고당 1회 한정"으로 실패
- LLM 평가가 실제 답변 품질을 더 정확히 반영

### 4. 할루시네이션 (13건/26건 = 50%)
- LLM이 질문에 명시된 상품이 아닌 다른 상품으로 답변하는 케이스
- 검색 결과에 해당 상품이 없을 때 다른 상품으로 대체 답변하는 문제

### 5. Rate Limit
- 30개 연속 평가 시 429 에러로 4건 실패
- 평가 간 딜레이 추가 또는 재시도 로직 필요
